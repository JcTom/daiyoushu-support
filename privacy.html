隐私政策

更新日期及生效日期：2026年11月6日

适用范围

本政策适用于“贷有数”iOS 应用。隐私联系邮箱：97413240@qq.com。

数据处理

当前版本无需注册账号，不向开发者服务器上传贷款金额、利率、期限、还款日期、计算结果或保存的方案。计算在设备本地完成。应用未接入广告、用户追踪或第三方统计 SDK，不请求通讯录、位置、相机或麦克风权限。

本地保存与删除

命名方案及计算便签保存在设备本地；普通计算历史仅保留在当前会话中。可通过应用提供的操作管理保存内容，或卸载应用删除其本地数据。设备系统备份可能包含应用数据，其处理遵循你的 Apple 备份设置；恢复备份可能恢复此前数据。

支持沟通

主动通过邮件联系我们时，我们会收到你提供的邮箱、问题描述及附件，仅用于处理咨询。请勿发送身份证号、银行卡号或其他不必要的敏感信息。如需删除支持邮件，请通过同一邮箱提出。

网页与第三方服务

本政策网页部署至 GitHub Pages 后，网页访问由 GitHub 提供服务，GitHub 可能处理访问日志等信息。网页访问与应用内的本地贷款计算相互独立。请参阅 GitHub 隐私声明。

未成年人及政策更新

本应用不面向儿童收集个人信息。功能或数据处理方式变化时会更新本政策，并在适用时取得必要授权。有关隐私的问题请联系上述邮箱。
